## Run Locally

### Prerequisites

- Node.js
- pnpm

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Devanshgoyal-os/Devansh-Goyal-Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Devansh-Goyal-Portfolio
   ```

3. Install dependencies:

   ```bash
   pnpm install
   ```

4. Start the development server:

   ```bash
   pnpm --filter @workspace/devansh-portfolio run dev
   ```

> Note: The development server may require the `PORT` and `BASE_PATH` environment variables, depending on the Vite configuration.
